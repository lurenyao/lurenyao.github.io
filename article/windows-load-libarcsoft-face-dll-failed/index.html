windows-load-libarcsoft_face-dll-failed

约 138 字小于 1 分钟

arcsoft人脸识别libarcsoft_face.dll

2025-10-18

虹软的人脸识别活体检测功能，添加到项目（WinForm）中后，在Windows下运行时，会报如下错误：

Cant’t find dependent library

经过研究调查，在DLL依赖检查工具的帮助下，发现缺少了msvcr120.dll文件。

安装Visual C++ Redistributable Packages for Visual Studio 2013即可解决。

若该版本找不到，更高版本的也行。
