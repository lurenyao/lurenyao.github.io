用Navicat连接达梦数据库

约 530 字大约 2 分钟

达梦navicat

2025-10-12

若需要连接达梦数据库，你必须先在你的系统中安装所需达梦 ODBC 驱动程序。请根据以下安装步骤操作。

提示：目前navicat 17.3版以上已经默认支持达梦数据库了，所以不用安装ODBC驱动程序。

Windows

安装介绍

  1. 下载驱动器
    • 请从此链接下载 Windows 版本 ODBC 驱动程序包：
    • https://dn.navicat.com/drivers/dameng_odbc_win.zip
  2. 解压缩包
    • 将下载的 .zip 文件内容解压到你的计算机上的某个位置。例如，C:\DamengDriver
  3. 运行安装脚本
    • 定位到你刚解压的驱动器文件所在的路径（如，C:\DamengDriver）。
    • 双击 install_odbc.bat 文件以开始安装文件。
    • 将弹出用户账户控制（UAC）提示，请求是否允许运行该程序。单击“是”，允许安装程序以管理员权限运行。
  4. 确认安装路径
    • 该脚本将提示你输入安装目标。你可以仅按 Enter 键即可接受默认位置（解压文件的目录）。
  5. 重启 Navicat 测试

Linux

安装介绍

  1. 下载驱动器
    • 请从以下链接下载 Linux 达梦 ODBC 驱动程序包： https://dn.navicat.com/drivers/dameng_odbc_linux.tar.gz
  2. 解压缩包
    • 打开终端
    • 定位到你刚解压缩文件所在的路径（如，~/Download），并使用以下命令解压压缩包：
tar -xzf dameng_odbc_linux.tar.gz
  1. 运行安装脚本
    • 在你的终端，导航到新创建的目录（该名称将与解压缩的文件内容相对应）：
cd dameng_odbc_linux
  • 使安装脚本可执行：
chmod +x install_odbc.sh
  • 使用 sudo 以管理员权限运行脚本。这是修改系统配置文件所必需的。
sudo ./install_odbc.sh
  1. 确认安装路径
    • 该脚本将提示你输入安装目标。你可以仅按 Enter 键即可接受默认位置（/opt/dameng_odbc） 。
  2. 重启 Navicat 测试
