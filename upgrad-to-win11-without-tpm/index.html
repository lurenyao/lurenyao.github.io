一条命令完美绕过Windows 11要求！

约 579 字大约 2 分钟

windowswindows11tpm

2025-10-29

随着Windows 10操作系统正式停止支持，许多硬件不符合Windows 11要求的旧电脑，面临着系统升级的困境。

不过Windows Latest发现，用户现在可以利用一个简单的命令，无需依赖第三方工具，就能完美绕过硬件检查，将旧PC升级至最新的Windows 11 25H2。

Windows 11 25H2的官方最低硬件要求包括：至少双核1GHz处理器、TPM 2.0模块、至少4GB内存以及安全启动。

Windows Latest证实，他们使用两台没有TPM 2.0、仅有2GB内存且未启用安全启动的Windows 10旧PC进行了测试，证明以下方法运作良好：

  1. 准备ISO文件：检查你的Windows 10语言版本（“设置”>“时间与语言”>“语言”），然后前往微软官网，下载对应语言版本的Windows 11 25H2 ISO文件。
  2. 挂载 ISO：下载完成后，将ISO文件挂载为虚拟光驱。
  3. 打开管理员模式的命令提示符： 使用Win + R键打开“运行”窗口，输入cmd，然后按下Ctrl + Shift + Enter键，以管理员模式开启命令提示符。
  4. 执行绕过命令：导航至ISO文件所在盘符，然后输入以下命令并按下Enter键：setup.exe /product server

在安装过程中，由于是非正式升级，建议选择“暂时不更新”，以跳过检查驱动程序和可选功能的步骤。

在下一步中，务必选择“保留文件、设置和应用程序”选项，以避免进行全新安装而丢失数据。

升级完成后，如果右下角仍然出现“不符合系统要求”的提示，可以通过修改注册表来消除：

  1. 使用Win + R组合键打开“运行”窗口，输入regedit，打开注册表编辑器。
  2. 找到路径HKEY_CURRENT_USER\Control Panel\UnsupportedHardwareNotificationCache。
  3. 将SV2的DWORD值从1修改为0。
  4. 重启电脑。

完成这些步骤后，你的旧PC就能在不符合最低要求的情况下，顺利运行Windows 11 25H2。
